
# Visualizations

This directory contains Python scripts for exploring Open Library ratings and publication trends.

## Planned Scripts

- `rating_visualization.py` — visualize rating distributions and related summaries.
- `publication_trends.py` — explore publication trends by year.

## Requirements

Install the Python dependencies listed in the root `requirements.txt`.

## Before Running

1. Verify that the scripts reference the correct input files or database.
2. Confirm that the required data is available.
3. Check that output paths exist.
4. Run the scripts in a configured Python environment.

The exact outputs depend on the source data and the implementation of each script.
